# NEM documentation

This directory is the language-facing documentation for NEM.

## Topics

- [language/overview.md](language/overview.md): high-level view of the language and its architecture
- [language/syntax.md](language/syntax.md): the concrete syntax supported by the current compiler
- [language/semantics.md](language/semantics.md): the validation rules and language-level guarantees

## Scope

These docs describe what the language intends to be and what the current compiler actually supports. They are meant to stay aligned with the implementation in the `nemc` repository.
